# Quotation PDF rendering

Quotation PDFs are generated by `backend/app/quotations/pdf.py::render_quotation_pdf`.
The quotation preview, download endpoint, print action, and email attachment all
use this same renderer and saved quotation data.

## Renderer selection

`PDF_RENDERER=auto` (the default) uses WeasyPrint when it can import its native
runtime. If the native runtime is unavailable, it explicitly logs the reason
and uses the portable ReportLab renderer. `PDF_RENDERER=weasyprint` makes a
missing native runtime a 503 PDF-generation failure; `PDF_RENDERER=reportlab`
selects the portable renderer directly.

Every successful generation emits a safe diagnostic with the quotation ID,
renderer, format, and result. No quotation contents or credentials are logged.

## Windows WeasyPrint setup

The Python package alone is not sufficient on Windows. WeasyPrint requires the
GTK/Pango/GLib native runtime, including `libgobject-2.0-0` and its dependent
libraries, available through the process DLL search path. Install the current
GTK runtime using the WeasyPrint Windows installation instructions, restart
the terminal, and verify with:

```powershell
python -c "import weasyprint; print(weasyprint.__version__)"
```

Do not commit DLLs or user-specific paths. Linux production deployments should
install the distribution packages for Pango, Cairo, and GLib alongside the
Python requirements. ReportLab remains available as a portable renderer for
local environments that intentionally choose `PDF_RENDERER=reportlab`.

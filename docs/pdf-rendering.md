# Quotation PDF rendering

Quotation PDFs are generated by `backend/app/quotations/pdf.py::render_quotation_pdf`.
The quotation preview, download endpoint, print action, and email attachment all
use this same ReportLab/SVG renderer and saved quotation data.

Every successful generation emits a safe diagnostic with the quotation ID,
renderer, format, and result. No quotation contents or credentials are logged.
No native browser, Pango, or GLib runtime is required.
